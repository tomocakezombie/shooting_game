# Terminal Shooting Game

ターミナル上で動作する2人対戦型シューティングゲームです。  
サーバー／クライアント構成でネットワーク対戦を行います。

## 概要

- **2つのマップ（ワールド）** を行き来しながら相手を撃ち合う対戦ゲーム
- TCP/IPソケット通信による **ネットワーク対戦**
- **ncurses** によるターミナル描画
- 各プレイヤーの HP は **5**。先に相手の HP を 0 にした方が勝利

## ゲーム画面構成

```
+-----------------------------+  ← メインウィンドウ（通常世界）
|                             |
+-----------------------------+
+-----------------------------+  ← サブウィンドウ（異世界）
|                             |
+-----------------------------+
+-------------------+            ← ステータスウィンドウ（HP表示）
| You:   ■ ■ ■ ■ ■  |
| Enemy: ■ ■ ■ ■ ■  |
+-------------------+
```

## 必要環境

- Linux / macOS
- GCC
- ncurses ライブラリ (`libncurses-dev` など)

## ビルド方法

```bash
make
```

生成される実行ファイル:

| ファイル | 説明 |
|----------|------|
| `tagServer` | サーバー側（先に起動する） |
| `tagClient` | クライアント側 |

```bash
# クリーン
make clean
```

## 起動方法

### サーバー側（ポート 10000 で待機）

```bash
./tagServer
```

### クライアント側

```bash
# サーバーと同じマシンの場合
./tagClient

# 別マシンのサーバーに接続する場合
./tagClient <サーバーのホスト名またはIPアドレス>
```

## 操作方法

| キー | 操作 |
|------|------|
| `↑` `↓` `←` `→` | 移動 |
| `Space` / `Enter` | 最後に移動した方向へ弾を発射 |
| `i` | 上方向へ弾を発射 |
| `k` | 下方向へ弾を発射 |
| `j` | 左方向へ弾を発射 |
| `l` | 右方向へ弾を発射 |
| `p` | ゲーム終了 |

## ゲームルール

- HP は各プレイヤー **5**
- 相手の弾に当たると HP が **1** 減少
- 先に HP が **0** になったプレイヤーの負け
- マップ上の `#` は **障害物**（通過・弾貫通 不可）
- マップ上の `W` は **ワープポイント**。踏むと異世界へ移動

### 2つのワールド

| ワールド | 説明 |
|----------|------|
| 通常世界 | ゲーム開始時にいる世界（メインウィンドウ） |
| 異世界 | ワープ後に移動する世界（サブウィンドウ） |

両ワールドは独立して表示されます。異なるワールドにいる相手の弾は当たりません。

## ファイル構成

```
.
├── Makefile
├── snet.h          # ネットワークライブラリヘッダ
├── snet.a          # ネットワークライブラリ（静的ライブラリ）
├── tagGame.h       # ゲームモジュールヘッダ
├── tagGame.c       # ゲームロジック（描画・移動・弾・判定）
├── tagServer.c     # サーバーメイン
├── tagClient.c     # クライアントメイン
├── O-map.txt       # 通常世界マップ定義
├── S-map.txt       # 異世界マップ定義
├── result_win.txt  # 勝利画面アスキーアート
└── result_lose.txt # 敗北画面アスキーアート
```

## マップファイルフォーマット

```
<行数>, <列数>
<マップデータ>
```

| 文字 | 意味 |
|------|------|
| `#`  | 障害物 |
| `W`  | ワープポイント（異世界へ移動） |
| `T`  | ワープ先（着地地点） |
| ` `  | 通路 |
